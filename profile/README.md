# Bidaide

**bide**（道）+ **-kide**（共にする者）— バスク語の語根から作った名前です。

トロントで出会った仲間で作った組織です。
それぞれ違う理由で日本を出て、たまたま同じ街で同じ時期を過ごしました。
帰国した今も、同じ方向に歩き続けています。

Bidaide は特定のプロダクトの名前ではなく、
その「一緒に歩いている状態」そのものに付けた名前です。
この下で何を作るかは、これから変わっていきます。

**発音**：ビダイデ / bee-DIE-deh

---

## English

**Bidaide** is a coined word, built from two Basque roots:
_bide_ — "path," and _-kide_ — "one who shares it."

Bidaide started as a group of people who met in Toronto.
Different reasons for leaving Japan, the same city at the same time,
and — back home now — still walking the same direction.

The name doesn't belong to a product. It belongs to the fact
that the walking is still shared.

_Pronounced: bee-DIE-deh_
